## Consolidated candidate queue (ranked by expected impact × breadth)

1. **#P1 ArraySchema Proxy trap avoidance in library internals** — traps show
   9–22% across decoder/tick, callbacks, heavy-tick, view-churn. Decode/encode
   internals should touch `$proxyTarget` directly (refs map, symbol-method
   calls). User-facing indexing stays proxied. (Proxy itself is a constraint —
   compare via `$changes` gotcha stands.)
2. **#C1 callbacks registry plain-object → Map** — triggerChanges 8.4% self;
   integer-keyed plain object is dictionary-mode; not dead-list adjacent.
3. **#S1 encodeView concatBytes** — per-view alloc+copy; reuse a per-view
   scratch buffer or write shared+view contiguously. API caveat: returned
   buffer must remain valid until transport send.
4. **#E4 Root.add** — 13.8% on construction ticks, 5–6% on churn.
5. **#E2 Root._appendToList pool starvation** — steady-state node allocs.
6. **#E5 forEachChild entries() iterator** — pair-array per child on every
   subtree walk (construction, view.add, GC walk).
7. **#S3 markInvisible/invisibleViews growth + StateView._add walk**.
8. **#E1 [$onEncodeEnd]/[$onDecodeEnd] gating** — run compaction only when a
   delete occurred.
9. **churn: de-closure garbageCollectDeletedRefs + dirty-gate** (steady-state
   confirmed NOT hot — churn-only win).
10. **#E3 HeapNumber boxing in setters** — investigate-only (adjacent to dead
    SoA/inline-slots).
11. Known-live leftovers still visible: `forEachWithCtx` (5%+),
    `MapJournal.indexOf` (1–2% + allocs), `encodeChangeCb` (2%).

Explicitly NOT queued (dead): setter bypass, decodeValue monomorphization,
DataChange pooling, per-ref callback gate, structured callback slots,
checkInheritedFlags bitmask, setParent-chain refactors, $refId pre-install.
